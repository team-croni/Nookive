# Security policy

## Supported versions

Security fixes are currently provided for the latest version on the default
branch and the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Until a
dedicated security contact is published, contact the repository maintainer
privately through the GitHub security advisory workflow. Include a clear
description, affected version/commit, reproduction steps, and impact. Do not
include real credentials, private documents, or personal data in a report.

Nookive is designed to process indexed content locally. A local index and the
temporary embedding server may still contain sensitive information, so treat
the app's data directory and diagnostic logs as private.
